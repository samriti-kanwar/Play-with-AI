# 🧠 AI Puzzle Game Hub - Challenge Your Mind! 🎮  

Welcome to **AI Puzzle Game Hub**, a collection of **classic brain-teasing puzzles**, all powered by Python! Whether you're solving the legendary **Tower of Hanoi**, cracking a **puzzle problem**, or navigating through **maze pathfinding**, this project lets you **put your problem-solving skills to the test**. 🚀  

## 🎯 What’s Inside?  
This hub offers three **fun and interactive AI-powered puzzle games**:  
✅ **🎯 Tower of Hanoi** – Move stacked disks using strategic logic!  
✅ **🧩 Puzzle Problem** – Solve numerical or visual puzzles efficiently!  
✅ **🗺️ Maze Pathfinding** – Find the quickest way out of the maze!  

## 🚀 Built With  
- **Python** 🐍 (Core logic for the puzzles)  
- **Tkinter** 🎨 (GUI for easy interaction)  
- **Subprocess Handling** ⚡ (Launching puzzle scripts)  

## 🎮 How to Play  
1️⃣ Open the main program: `python Dashboard.py`  
2️⃣ Choose your puzzle from the interactive **AI Puzzle Game Hub**.  
3️⃣ Solve puzzles using strategy & logic.  
4️⃣ Keep playing and challenge yourself!
